Button Component

The Button component is a fundamental interactive element used throughout the Onity Design System. It provides multiple variants, sizes, and states to meet various design requirements and user interaction patterns.

Usage Guidelines

Purpose

Use buttons to trigger actions or submit information. Ensure each button has a clear, action-oriented label.

Placement

Position primary buttons prominently. Group related buttons horizontally with consistent spacing.

Accessibility

Ensure sufficient color contrast, keyboard navigation support, and clear focus states for all users.

Design Tokens

The following design tokens define the visual properties of the Button component:

Primary Color
#6366f1

Used for primary action buttons

Secondary Color

Implementation

To implement the Button component in your project, follow these best practices:

Import

Import the Button component from the Onity design package and include required dependencies.

Props

Configure buttons using props like variant, size, disabled, and onClick handlers for custom behavior.

Theming

Leverage design tokens for consistent styling across your application using CSS variables or theme providers.
