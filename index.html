  Guidelines
  
Best Practices

  
Rules for applying buttons across the Onity ecosystem to ensure consistency.


  

    

      
Do

      
    
        
  • Use Primary Filled for the single most important action on a screen.
    • 
        
  • Keep button labels clear, actionable, and short (1-3 words).
    • 
        
  • Use Error Filled only for destructive, unrecoverable actions (e.g., Delete Account).
    • 
        
  • Ensure buttons are spaced adequately for touch targets on mobile devices.
    • 
      

    

    

      
Don't

      
    
        
  • Don't place multiple Primary buttons next to each other in the same view.
    • 
        
  • Don't wrap button text to two lines. If text is too long, rethink the copy.
    • 
        
  • Don't use icons in a button unless they directly clarify the action.
    • 
        
  • Don't use White Outlined buttons on light backgrounds where they become invisible.
    •
